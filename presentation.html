Physics Motivation

Neutral Pion Decay & Particle Identification

Primary Physics Goal

Reconstruct pi0 to gamma-gamma Invariant Mass

Observe the neutral pion decay at the CERN PS T9 secondary hadron beamline by detecting two coincident photon showers in the electromagnetic calorimeter.

M_inv = sqrt(2 * E_g1 * E_g2 * (1 - cos theta)) ~ 135.0 MeV/c2

Key Measurements

  • Calorimetry: 4x4 Lead Glass -> E_gamma (MeV)
  • Cherenkov PID: e-/pi- separation (QDC threshold)
  • Tracking: DWC + Timepix3 (256x256 pixels)
  • Timing: S1/S2 Scintillator ToF (sub-ns TDC)

Beam Parameters

  • Momentum: 1 - 10 GeV/c
  • Composition: e-, pi-, mu-, p
  • Spill cycle: 0.4 s / 10 s
  • Flux: ~10^5 particles/spill

DAQ Architecture

Constellation Framework & Data Pipeline

What is Constellation?

Constellation is a decentralized, network-based DAQ framework developed at DESY/CERN. Each detector runs as an autonomous Satellite process, communicating over ZeroMQ.

Core Concepts

  • Satellites: Independent detector processes
  • FSM: NEW -> INIT -> ORBIT -> RUN -> SAFE
  • CDTP: Binary data transport (ZeroMQ)
  • CSCP: Control & state management
  • Groups: Logical network segmentation

Our Implementation

  • 8 Custom Satellites (Python)
  • Geant4/Monte Carlo physics engine
  • Poisson spill-cycle timing model
  • Protocol Buffers serialization
  • Kafka real-time streaming layer

Advanced Trigger Logic

Multi-Stage Hardware Coincidence Simulation

Full NIM-logic coincidence: S1 AND S2 AND [NOT BUSY] AND [Cherenkov TAG]

Trigger Decision Flow

  1. Particle enters -> S1/S2 fire (Poisson PE)
  2. Check timing: |t_S1 - t_S2| <= 10 ns
  3. Check DAQ BUSY inhibit gate
  4. If free -> TRIGGER ACCEPTED
  5. Set BUSY for 3.5 ms (readout dead-time)
